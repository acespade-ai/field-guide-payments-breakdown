# The Field Guide to Global Payments — Visual Study Guide

A 6-page visual study guide to Sophia Goldberg's *The Field Guide to Global Payments*
(Stripe Press, 2022), built as an entry for taskmarket.dev task TSK-C1NHS8PZ.

- **Submission:** SUB-S578ZW16 (Tempo chain, 0.50 USDC bounty)
- **Deliverable:** [field-guide-to-global-payments-visual-study-guide.pdf](field-guide-to-global-payments-visual-study-guide.pdf)

## What's inside

1. **Cover + section map** — the book's four sections at a glance.
2. **One card transaction, mapped** — four-party model, authorization → capture/clearing → settlement, fee stack, decline/liability callouts.
3. **Cards, unpacked** — players, card types, open vs closed loop, acceptance environments, orchestration.
4. **Non-card taxonomy** — bank, delayed, wallets, cash/ATM, crypto/DeFi + the regional map.
5. **Rules & risk cheat sheet** — PCI DSS, tokenization, 3DS, PSD2/SCA, AML/KYC, network rules + fraud types.
6. **Business models + takeaways** — subscriptions vs marketplaces vs B2B, and the ten takeaways that matter.

Source: the book itself (fieldguidetoglobalpayments.com). Figures such as the ~85%
authorization rate are the book's own. Built with reportlab (`build_guide.py`).
